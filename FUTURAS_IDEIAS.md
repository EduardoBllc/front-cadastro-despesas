# Ideias Futuras

## Tela de Configurações Gerais

Atualmente a tela de Configurações cobre apenas parâmetros de abastecimento.
Expandir para uma tela completa de configurações do sistema, incluindo:

- Agrupamento por seções (Abastecimento, Aparência, Notificações etc.)
- Possibilidade de resetar configurações para o padrão
- Configurações por usuário (quando houver autenticação)
